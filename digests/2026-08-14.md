## AI + machine learning

### [Announcing: Azure Databricks Runtime 10.4 LTS will reach end of life on November 1, 2026](https://azure.microsoft.com/en-us/updates?id=569353)

**Status:** Effective | **Published:** 2026-08-14 | **Products:** Azure Databricks | **Tags:** Announcement

Azure Databricks Runtime 10.4 LTS will reach end of life on November 1, 2026, requiring customers to migrate workloads to supported versions to avoid disruption.

- Databricks Runtime 10.4 LTS reached end of support on March 18, 2025, and will be unusable after November 1, 2026.
- After end of life, workloads on version 10.4 LTS will no longer run and the runtime will not be selectable in the UI.
- Customers must migrate clusters and workloads to supported Databricks Runtime versions before November 1, 2026 to prevent service disruption.
- Microsoft provides queries to identify legacy Databricks Runtime usage and jobs that require upgrading to assist customers in migration planning.

Documentation: [Databricks support lifecycles - Azure Databricks](https://learn.microsoft.com/en-us/azure/databricks/release-notes/runtime/databricks-runtime-ver)
