### [Generally Available: Control plane metrics collection for AKS with Managed Prometheus](https://azure.microsoft.com/en-us/updates?id=568830)

**Status:** Launched | **Published:** 2026-08-13 | **Products:** Azure Kubernetes Service (AKS), Azure Monitor | **Tags:** Feature

Azure Kubernetes Service (AKS) now generally supports native control plane metrics collection via Azure Monitor Managed Service for Prometheus, enhancing observability into key control plane components for better workload and scaling insights.

- Capability: Collects metrics from AKS control plane components including API server, etcd, kube-scheduler, kube-controller-manager, cluster autoscaler, and node auto-provisioning.
- Availability: Feature is generally available and enabled through the managed service for Prometheus add-on with managed identity authentication.
- Customer Impact: Enables platform teams to monitor control plane performance and interactions over time, improving operational insights and troubleshooting.
- Usage: Metrics are stored in an Azure Monitor workspace and can be queried via Prometheus explorer or Azure Managed Grafana with provided dashboard templates.

Documentation: [Monitor AKS Control Plane Metrics - Azure Kubernetes Service](https://learn.microsoft.com/en-us/azure/aks/control-plane-metrics-monitor)

## Databases

### [Generally Available: Pre-upgrade validation checks for Azure Database for PostgreSQL Flexible Server](https://azure.microsoft.com/en-us/updates?id=568419)

**Status:** Launched | **Published:** 2026-08-13 | **Products:** Azure Database for PostgreSQL | **Tags:** Feature

Azure Database for PostgreSQL Flexible Server now offers generally available pre-upgrade validation checks to proactively identify and resolve major version upgrade blockers, improving upgrade success and operational predictability.

- Pre-upgrade validation checks can be run via Azure portal and Azure CLI with the --validate-only option.
- Checks identify potential upgrade blockers like unsupported extensions, replication slots, and configuration mismatches before starting the upgrade.
- This proactive validation reduces failed upgrade attempts, troubleshooting effort, and simplifies upgrade planning for production workloads.
- Validation requires connectivity to all databases, is not supported on read replicas, and should be run during low activity periods to avoid interference.

Documentation: [Major Version Upgrades - Azure Database for PostgreSQL](https://learn.microsoft.com/en-us/azure/postgresql/configure-maintain/concepts-major-version-upgrade#upgrade-validation-checks)

## Storage

### [Generally Available: Live Resize for Shared Premium SSD v2 and Ultra Data Disks](https://azure.microsoft.com/en-us/updates?id=569281)

**Status:** Launched | **Published:** 2026-08-13 | **Products:** Azure Disk Storage | **Tags:** Feature

Live Resize for shared Premium SSD v2 and Ultra data disks is now generally available, enabling dynamic storage expansion without downtime to optimize costs and application availability.

- Allows dynamic expansion of shared Premium SSD v2 and Ultra disks without application disruption.
- Supports cost optimization by starting with smaller disks and resizing as needed without downtime.
- Applies to shared disks used across multiple Linux VMs with specific limitations on caching, bursting, and encryption.
- Billing for shared Premium SSD v2 and Ultra disks is based on provisioned IOPS and throughput, with no extra per-VM mounting charges.

Documentation: [Share an Azure managed disk across VMs - Azure Virtual Machines](https://learn.microsoft.com/en-us/azure/virtual-machines/disks-shared)
