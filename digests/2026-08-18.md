## Compute

### [Retirement: Azure VMware Solution License-included service will be retired August 30, 2027](https://azure.microsoft.com/en-us/updates?id=569535)

**Status:** Retirement | **Published:** 2026-08-18 | **Products:** Azure VMware Solution | **Tags:** Retirements

Azure VMware Solution's license-included service will be retired by August 30, 2027, requiring customers to transition to a bring-your-own-license (BYOL) model due to Broadcom's updated VMware licensing policies, ensuring compliance and uninterrupted service.

- The AVS license-included Reserved Instance SKUs will retire on August 30, 2027, requiring customers to purchase portable Broadcom VMware Cloud Foundation (VCF) licenses and switch to AVS VCF BYOL SKUs.
- License-included Pay-As-You-Go (PayGo) SKUs will retire earlier on October 15, 2026, with AV36 SKU retirement aligned to August 30, 2027.
- Customers must plan and execute their transition or exit AVS before August 31, 2027, to avoid service disruption.
- Microsoft provides support through account teams, self-service exchanges, and guidance to facilitate a smooth transition to the new licensing model.

Documentation: [UPDATED: Broadcom VMware Licensing Changes: What Azure VMware Solution Customers Need to Know | Microsoft Community Hub](https://techcommunity.microsoft.com/blog/azuremigrationblog/updated-broadcom-vmware-licensing-changes-what-azure-vmware-solution-customers-n/4448784)

### [Generally Available: Managed Instance on Azure App Service](https://azure.microsoft.com/en-us/updates?id=568952)

**Status:** Launched | **Published:** 2026-08-18 | **Products:** App Service | **Tags:** Services, Feature

Managed Instance on Azure App Service is now generally available, enabling seamless migration of complex Windows-based .NET applications to a fully managed PaaS environment with enhanced performance, security, and operational control.

- Supports migration of legacy .NET Framework apps with Windows-specific dependencies and no code changes, reducing modernization barriers.
- Available in at least 8 Azure regions with zone redundancy, Premium v4 integration, and enhanced observability via Azure Monitor and Application Insights.
- Enterprise-grade features include 99.95% SLA, Azure Policy and Defender for Cloud integration, Managed Identity by default, and infrastructure-as-code support with Bicep, Terraform, and ARM templates.
- Improves migration timelines from months to weeks, reduces infrastructure footprint by consolidating Windows Server VMs, and offers seamless deployment and troubleshooting via Azure portal, CLI, and Azure Bastion RDP.

Documentation: [Announcing General Availability of Managed Instance on Azure App Service | Microsoft Community Hub](https://techcommunity.microsoft.com/blog/AppsonAzureBlog/announcing-general-availability-of-managed-instance-on-azure-app-service/4541283)

## Networking

### [Public Preview: Ipv6 support in Azure Firewall](https://azure.microsoft.com/en-us/updates?id=569520)

**Status:** In preview | **Published:** 2026-08-18 | **Products:** Azure Firewall | **Tags:** Features, Security

Azure Firewall now supports IPv6 in public preview, enabling dual-stack mode for IPv4 and IPv6 traffic to help organizations secure modern dual-stack network architectures.

- Supports native IPv6 network-rule filtering and DNS Proxy for IPv6 traffic.
- Available in most Azure regions except Israel Central, Israel Northwest, Qatar Central, UAE Central, and UAE North, with portal deployment support coming soon.
- Limitations include no support yet for threat intelligence, IDPS, Explicit Proxy, IP Groups, and inability to revert from dual-stack to IPv4-only mode.
- Customers can upgrade existing Azure Firewalls to dual-stack by adding IPv6 address spaces and public IPs via CLI or PowerShell, enhancing security for cloud, hybrid, and internal IPv6 traffic.

Documentation: [Deploy Azure Firewall in dual stack mode (preview)](https://learn.microsoft.com/en-us/azure/firewall/deploy-dual-stack-firewall)
