## Hybrid + multicloud

### [Generally Available: Summarized advertised gateway prefixes for route advertisement](https://azure.microsoft.com/en-us/updates?id=569743)

**Status:** Launched | **Published:** 2026-08-20 | **Products:** Azure ExpressRoute, Virtual Network, VPN Gateway | **Tags:** Features, Management, Services

Azure VPN Gateway and ExpressRoute Gateway now generally support advertising summarized gateway prefixes to on-premises networks, reducing route advertisement counts and enabling scalable hub-and-spoke deployments.

- Supports aggregated (summarized) IPv4 and IPv6 prefixes for route advertisement on ExpressRoute and VPN Gateways.
- Helps large hub-and-spoke architectures avoid advertised-prefix limits by advertising covering prefixes instead of many individual spoke prefixes.
- Summarized prefixes suppress advertisement of covered spoke address spaces while preserving connectivity for uncovered spaces.
- The feature is effective once a gateway subnet and gateway exist in the virtual network, and summarized prefixes can be configured beforehand.

Documentation: [Advertised gateway prefixes in Azure virtual networks - Azure Virtual Network](https://learn.microsoft.com/en-us/azure/virtual-network/advertised-gateway-prefixes-overview)

## Management and governance

### [Announcing: Azure Copilot introduces direct access to agents](https://azure.microsoft.com/en-us/updates?id=569685)

**Status:** Effective | **Published:** 2026-08-20 | **Products:** Azure Copilot | **Tags:** Announcement

Azure Copilot now allows direct access to specialized agents by default, enabling faster, more focused cloud operations and giving admins granular control over agent availability.

- Users can directly invoke four agents—Troubleshooting, Deployment, Optimization, and Resiliency—from the Azure Copilot chat starting August 2026.
- Agents are enabled by default for Azure Copilot users, streamlining the path from question to action with purpose-built expertise.
- Global administrators can enable or disable individual agents via the Azure Copilot Admin Center, supporting incremental AI adoption aligned with governance.
- This update maintains existing pricing models with no additional fees for core agents, while observability agent continues with usage-based billing.

Documentation: [Azure Copilot Introduces Direct Access to Agents | Microsoft Community Hub](https://techcommunity.microsoft.com/blog/AzureInfrastructureBlog/azure-copilot-introduces-direct-access-to-agents/4547932)
