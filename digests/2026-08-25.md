## Compute

### [Generally Available: Azure 248 and 372 vCPU sizes for D/E v7 series VMs](https://azure.microsoft.com/en-us/updates?id=569546)

**Status:** Launched | **Published:** 2026-08-25 | **Products:** Virtual Machines | **Tags:** Feature

Azure has made 248 and 372 vCPU D/E v7 series VMs generally available, offering up to 20% better compute performance and enhanced networking and storage capabilities to support larger, latency-sensitive workloads.

- New Dlsv7, Dsv7, and Esv7 VMs scale up to 372 vCPUs and 2.8 TiB memory, enabling larger in-memory databases and agentic AI workloads.
- Up to 400 Gbps networking bandwidth and up to 800k IOPS with 20 GBps throughput to remote storage on 372 vCPU Esv7/Edsv7 sizes.
- Improved local NVMe storage performance with up to 9.6M IOPS and 53 GBps throughput on 372 vCPU Ddsv7/Edsv7 sizes.
- These VM sizes are now generally available in multiple regions including Central US, East US, Germany West Central, and Sweden Central.

Documentation: [Dsv7 size series - Azure Virtual Machines](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/general-purpose/dsv7-series?tabs=sizebasic)

### [Announcing: Aspire 13.5 has shipped](https://azure.microsoft.com/en-us/updates?id=569910)

**Status:** Effective | **Published:** 2026-08-25 | **Tags:** Announcement

Aspire 13.5 enhances the developer experience by refreshing the dashboard, expanding interaction capabilities, supporting cross-scope Azure references and Kubernetes persistent volumes, and integrating live terminals within the apphost.

- Dashboard and aspire.dev refreshed with improved log filtering, telemetry, and health-check handling for better usability.
- Interaction Service expanded with file import support, progress dialogs, and named arguments enabling richer, integrated developer workflows.
- Live terminals added inside the dashboard allowing interactive terminal sessions with multi-viewer support, simplifying management of REPLs and shells.
- Support for Kubernetes persistent volumes and cross-scope Azure resource references added, enabling more accurate infrastructure modeling and resource sharing.
- Aspire CLI now available via multiple package managers (Homebrew, WinGet, npm, Nix, mise, NuGet) for easier installation and updates.

Documentation: [Aspire 13.5: Fresh pixels and better workflows | Aspire Blog](https://devblogs.microsoft.com/aspire/whats-new-aspire-13-5/)
