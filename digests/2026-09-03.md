## Databases

### [Public Preview: Reader Endpoint for Azure Database for MySQL](https://azure.microsoft.com/en-us/updates?id=569653)

**Status:** In preview | **Published:** 2026-09-02 | **Products:** Azure Database for MySQL | **Tags:** Feature

Azure Database for MySQL - Flexible Server now supports a reader endpoint in public preview, enabling automatic load balancing of read-only traffic across multiple replicas to simplify connection management and improve scalability.

- Introduces a reader endpoint that automatically balances read-only connections across up to 10 read replicas per primary server.
- Simplifies application architecture by providing a single endpoint for all read operations instead of managing individual replica endpoints.
- Enhances scalability and fault tolerance by distributing read traffic efficiently among replicas.
- Currently available in public preview for Azure Database for MySQL - Flexible Server.

## Networking

### [Public Preview: Azure Front Door profile and route level WAF policies](https://azure.microsoft.com/en-us/updates?id=569804)

**Status:** In preview | **Published:** 2026-09-02 | **Products:** Azure Front Door, Web Application Firewall | **Tags:** Features, Security

Azure Front Door WAF now supports profile, domain, and route level policy associations in public preview, enabling more flexible and granular security configurations.

- WAF policies can be associated at profile, domain, or route scope to balance broad baseline protection with targeted controls.
- Route-level policies take precedence over domain-level, which take precedence over profile-level policies for requests matching multiple scopes.
- This reduces policy duplication and allows specific protections for sensitive paths like sign-in or checkout routes.
- Available in public preview, customers can configure these policies via the Azure portal to better tailor security to their application needs.

Documentation: [What Is Azure Web Application Firewall on Azure Front Door?](https://learn.microsoft.com/en-us/azure/web-application-firewall/afds/afds-overview)
