## Networking

### [Generally Available: Azure Virtual Network Manager IPAM in additional Azure regions](https://azure.microsoft.com/en-us/updates?id=570557)

**Status:** Launched | **Published:** 2026-09-03 | **Products:** Azure Virtual Network Manager | **Tags:** Features, Management, Regions & Datacenters, Services

Azure Virtual Network Manager IPAM is now generally available in additional US Gov and China regions, enabling centralized, cross-region IP address management to prevent conflicts and improve network governance.

- IPAM is generally available in US Gov Virginia, US Gov Texas, US Gov Arizona, China North 3, and China East 3 regions.
- Centralizes IP address planning and allocation with hierarchical pools to prevent overlapping CIDRs across Azure, on-premises, and multi-cloud environments.
- Supports cross-region association, allowing management of IP addresses for virtual networks across multiple regions for global governance.
- Integration with Azure Policy enforces use of designated IP pools, ensuring consistent and conflict-free IP allocation for new and existing virtual networks.

Documentation: [What is IP address management (IPAM) in Azure Virtual Network Manager?](https://learn.microsoft.com/en-us/azure/virtual-network-manager/concept-ip-address-management)
