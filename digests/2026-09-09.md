The Azure Developer CLI (azd) Extension Framework is now generally available, enabling developers and organizations to create, distribute, and manage custom CLI extensions that streamline and standardize Azure application development workflows.

- The GA release stabilizes extension interfaces, expands lifecycle and provider integration, and improves authoring and publishing workflows.
- Extensions can add commands, automate workflows, integrate services, and guide developers through complex multi-step processes within the azd CLI.
- Supports multiple distribution methods including official, private, development, and nightly extension sources, as well as portable .zip packages.
- Empowers engineering platform teams and product teams to create tailored developer experiences that reduce friction and improve productivity in Azure application lifecycle management.

**Status:** Launched | **Published:** 2026-09-08 | **Products:** Azure Load Testing | **Tags:** Regions & Datacenters, Feature

Playwright Workspaces in Azure App Testing is now generally available in Australia East, Japan East, and Switzerland North, enabling scalable, cloud-hosted Playwright test execution with regional performance and secure data handling.

- Provides fully managed cloud-hosted browsers for running end-to-end Playwright tests with parallel execution and rich debugging artifacts.
- Available in three new Azure regions: Australia East, Japan East, and Switzerland North, ensuring consistent regional performance.
- Supports seamless integration with existing Playwright test suites and CI/CD pipelines without code changes.
- Ensures data security and compliance by encrypting all workspace data and keeping customer data within the deployed region.
