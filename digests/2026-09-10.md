## Compute

### [Generally Available: Azure Ephemeral OS Disk with full caching for VM/VMSS](https://azure.microsoft.com/en-us/updates?id=570551)

**Status:** Launched | **Published:** 2026-09-09 | **Products:** Virtual Machines | **Tags:** Features

Azure Ephemeral OS Disk with full caching is now generally available, providing significantly faster OS disk access and improved resilience for I/O-sensitive workloads by caching the entire OS image on local VM storage.

- Caches complete OS image on local storage to eliminate remote-storage reads after caching.
- Delivers up to 10× better I/O performance and low-millisecond OS disk access.
- Available for new VMs and VM Scale Sets with 8-core-and-larger GPU, storage-optimized, memory-optimized, HPC, general-purpose, and compute-optimized series across Azure public regions.
- Enables improved resilience during storage interruptions without slowing VM provisioning, configurable via Azure CLI, ARM templates, or REST APIs.

## Storage

### [Generally Available: User-bound user delegation SAS for Azure Storage](https://azure.microsoft.com/en-us/updates?id=569241)

**Status:** Launched | **Published:** 2026-09-09 | **Products:** Azure Blob Storage | **Tags:** Security, Feature

Azure Storage now generally supports user-bound user delegation SAS tokens, enhancing security by restricting SAS token usage to a specific end user identity.

- User-bound user delegation SAS extends existing user delegation SAS by binding the SAS token to an end user's Entra ID, ensuring only the intended user can use the token.
- This feature is generally available in all public Azure regions with no additional cost beyond standard storage transaction fees.
- Supports cross-tenant scenarios with configuration, allowing SAS tokens to be used by users in different tenants when enabled.
- Improves security best practices by leveraging Microsoft Entra credentials and RBAC, reducing the need to store account keys in application code.

Documentation: [Create a user delegation SAS - Azure Storage](https://learn.microsoft.com/en-us/rest/api/storageservices/create-user-delegation-sas)
