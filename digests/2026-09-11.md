## Compute

### [Generally Available: TLS/SSL certificate and end-to-end TLS encryption support for Azure Functions Flex Consumption](https://azure.microsoft.com/en-us/updates?id=570940)

**Status:** Launched | **Published:** 2026-09-10 | **Products:** Azure Functions | **Tags:** Features, Security, Feature

Azure Functions Flex Consumption plan now generally supports TLS/SSL certificates and end-to-end TLS encryption, enhancing security for custom domains and encrypted traffic.

- Supports up to 3 private (.pfx) and 3 public (.cer) certificates per function app via direct upload, Azure Key Vault import, or free App Service Managed Certificates.
- Enables custom domains, client-certificate authentication, and mutual TLS scenarios on Flex Consumption plan.
- End-to-end TLS encryption secures traffic between platform front ends and function workers.
- Available generally, improving security posture and compliance for enterprise customers using Azure Functions Flex Consumption.

Documentation: [Create and Manage Function Apps in a Flex Consumption Plan](https://learn.microsoft.com/en-us/azure/azure-functions/flex-consumption-how-to)

## Management and governance

### [Generally Available: Azure Copilot Troubleshooting Agent](https://azure.microsoft.com/en-us/updates?id=570980)

**Status:** Launched | **Published:** 2026-09-10 | **Products:** Azure Copilot | **Tags:** Features

Azure Copilot Troubleshooting Agent is now generally available, providing a unified, built-in tool that accelerates operational issue investigation and resolution by consolidating insights, context, and recommended actions in one experience.

- Enables faster troubleshooting by integrating diagnostics and operational context for Azure resources like AKS, VMs, and more.
- Accessible via Azure Copilot and Support + Troubleshooting in the Azure portal at no additional cost, with no extra licensing or query charges.
- Maintains customer control by respecting Azure RBAC and explaining findings with recommended actions for informed remediation decisions.
- Supports a conversational experience that evolves to cover more Azure services, enhancing operational efficiency and reducing reliance on external support.

Documentation: [Azure Copilot announces general availability of the Troubleshooting Agent | Microsoft Community Hub](https://techcommunity.microsoft.com/blog/appsonazureblog/azure-copilot-announces-general-availability-of-the-troubleshooting-agent/4554549)
