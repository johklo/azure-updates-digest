## Migration

### [Public Preview: Agentless migration of on-premises SMB file shares to Azure Files (SMB)](https://azure.microsoft.com/en-us/updates?id=570910)

**Status:** In preview | **Published:** 2026-09-11 | **Products:** Azure Storage Mover | **Tags:** Features

Azure Storage Mover now offers agentless migration of on-premises SMB file shares to Azure Files (SMB) in public preview, simplifying migration by eliminating the need for on-premises agents.

- Supports agentless migration from Windows Server or NAS SMB shares to Azure Files over private connections (VPN or ExpressRoute).
- Source credentials are securely stored in Azure Key Vault and accessed via Storage Mover managed identities.
- Migration jobs can be configured and run via Azure portal or CLI, with support for up to 500 million objects per job and up to 10 concurrent jobs per subscription.
- Currently in preview with limitations: only SMB 2.x/3.x supported, data is copied (not moved), and only one job per target share recommended to avoid conflicts.

Documentation: [Migrate on-premises SMB file shares to Azure Files using the agentless migration capability in Storage Mover](https://learn.microsoft.com/en-us/azure/storage-mover/agentless-on-premises-files-migration?tabs=portal)

### [Retirement: Azure Linux with OS Guard in Azure Kubernetes Service](https://azure.microsoft.com/en-us/updates?id=571257)

**Status:** Retirement | **Published:** 2026-09-11 | **Tags:** Retirements

Azure Linux with OS Guard in Azure Kubernetes Service is retiring by December 10, 2026, requiring customers to migrate to Azure Container Linux to maintain support and security updates.

- Support ends December 10, 2026: no new node pools, no new node images, and no security patches for existing Azure Linux with OS Guard node pools.
- Node images will be removed on March 10, 2027, causing scaling and remediation operations to fail on affected node pools.
- Migration options include in-place OS SKU migration to Azure Container Linux or creating new ACL node pools and migrating workloads.
- Azure Container Linux requires Trusted Launch with Secure Boot and vTPM, Azure CLI 2.86.0+, and has specific VM size and configuration requirements.

Documentation: [Tutorial: Migrate Nodes to Azure Container Linux (ACL) for Azure Kubernetes Service (AKS)](https://learn.microsoft.com/en-us/azure/azure-linux/tutorial-migrate-azure-container-linux-aks)
