## Networking

### [Generally Available: High-scale mesh in Azure Virtual Network Manager](https://azure.microsoft.com/en-us/updates?id=571572)

**Status:** Launched | **Published:** 2026-09-17 | **Products:** Azure Virtual Network Manager | **Tags:** Features, Management, Services

Azure Virtual Network Manager's high-scale mesh feature is now generally available, enabling customers to connect up to 3,000 virtual networks in a single mesh for simplified, scalable network connectivity.

- Supports up to 3,000 virtual networks in a single connected group mesh by default, with higher scale IP connectivity available on request.
- Simplifies management by eliminating the need for individual peerings, allowing direct bi-directional communication between virtual networks.
- Enables up to 20,000 private endpoints across connected groups when high-scale private endpoint feature is enabled.
- Improves network performance and security by supporting mesh and hub-and-spoke topologies with centralized connectivity configuration.

Documentation: [Connectivity Configurations in Azure Virtual Network Manager](https://learn.microsoft.com/en-us/azure/virtual-network-manager/concept-connectivity-configuration#enable-high-scale-private-endpoints-in-azure-virtual-network-manager-connected-groups)

### [Public Preview: Azure Payments HSM v2](https://azure.microsoft.com/en-us/updates?id=570509)

**Status:** In preview | **Published:** 2026-09-17 | **Tags:** Features, Security, Services

Azure Payments HSM v2 is now in public preview, offering a highly available, single-tenant payment HSM service that simplifies compliance and operational management for payment cryptography workloads.

- Provides isolated, single-tenant HSM clusters with exclusive administrative control for payment processing, key management, and PIN processing.
- Runs in PCI DSS and PCI 3DS compliant Azure data centers with FIPS 140-3 Level 3 certification, supporting stringent PCI security and compliance requirements.
- Reduces operational overhead by eliminating the need for physical HSM hardware procurement, deployment, and scaling, while ensuring high availability and low latency.
- Enables financial institutions and payment service providers to modernize payment cryptography with cloud-native infrastructure integrated into Azure virtual networks.

Documentation: [What is Azure Payment HSM v2?](https://learn.microsoft.com/en-us/azure/payment-hsm-v2/overview)
