### [Generally Available: Azure Sphere OS version 26.09 is now available](https://azure.microsoft.com/en-us/updates?id=572579)

**Status:** Launched | **Published:** 2026-09-21 | **Products:** Azure Sphere | **Tags:** Operating System

Azure Sphere OS version 26.09 is now generally available, updating the Linux kernel to version 6.1.x for long-term support, marking the final major kernel update before Azure Sphere's retirement in 2031.

- Updates Azure Sphere OS Linux kernel from 5.10.x to 6.1.x, aligning with Linux CIP Platform for Super Long-Term Support.
- No changes to SDK or new functional features; update is OS-only.
- Devices connected to the internet will automatically receive the OS update from the cloud.
- This is the final major kernel update before Azure Sphere retirement planned for 2031.

Documentation: [Support - Azure Sphere](https://learn.microsoft.com/en-us/azure-sphere/resources/support?view=azure-sphere-legacy)
