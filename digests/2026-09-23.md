### [Retirement: Support for Node.js 22 ends on April 30, 2027](https://azure.microsoft.com/en-us/updates?id=572771)

**Status:** Retirement | **Published:** 2026-09-22 | **Products:** Azure Functions | **Tags:** Retirements, Compliance, Security

Support for Node.js 22 in Azure Functions will end on April 30, 2027, requiring customers to upgrade to Node.js 24 to maintain security, support, and performance.

- Node.js 22 support and security updates will end on April 30, 2027; apps will continue running but without patches or support.
- Customers must upgrade to Node.js 24 before the deadline to avoid security vulnerabilities and ensure continued support eligibility.
- Upgrading involves updating function app runtime to version 4.x, verifying extension bundles, binding extensions, package dependencies, and local development tools compatibility.
- Testing and deployment best practices include using staging slots to minimize downtime and enable rollback during the upgrade process.

### [Public Preview: Flex Nodes for AKS](https://azure.microsoft.com/en-us/updates?id=571919)

**Status:** In preview | **Published:** 2026-09-22 | **Products:** Azure Kubernetes Service (AKS) | **Tags:** Feature

Flex Nodes for AKS, now in public preview, enable hybrid and edge infrastructure integration as connected worker nodes to a centralized AKS control plane, allowing consistent Kubernetes management while meeting latency, regulatory, and sovereignty requirements.

- Flex Nodes run on user-managed VMs or bare metal hosts outside the AKS-managed Azure VM model, extending AKS to hybrid and edge environments.
- The flex node agent bootstraps and maintains node configuration, enabling isolated Kubernetes node environments that integrate with the AKS cluster control plane.
- Supports multiple authentication methods and separate identities for secure communication with Azure and Kubernetes.
- Ideal for scenarios requiring local execution without local operations, such as AI inference, industrial apps, data residency needs, and capacity outside the cluster's Azure region.

Documentation: [What are flex nodes for AKS? (preview) - Azure Kubernetes Service](https://learn.microsoft.com/en-us/azure/aks/flex-nodes-for-aks-overview)
