## Mobile

### [Retirement: Azure Communication Services (ACS) standalone services will be retired on September 30, 2028](https://azure.microsoft.com/en-us/updates?id=557117)

**Status:** Retirement | **Published:** 2026-09-24 | **Products:** Azure Communication Services | **Tags:** Retirements

Microsoft will retire several standalone Azure Communication Services (ACS) offerings by September 30, 2028, requiring customers to transition to Teams-integrated solutions or update SDKs to maintain functionality.

- Multiple standalone ACS services including Email, SMS, Chat, and Number Management will be retired and cease functioning after September 30, 2028.
- ACS services with breaking changes, such as Voice/Video Calling SDK and Call Automation, will continue only when integrated with Microsoft Teams and require SDK updates to the latest major versions.
- New customers cannot sign up for retiring ACS services starting October 23, 2026; existing customers can use them until the retirement date to support transition.
- Customers must update applications to supported Teams-aligned services or face service disruption; Microsoft provides migration guidance and support resources to facilitate this transition.

Documentation: [Retirement and breaking changes guide for Azure Communication Services](https://learn.microsoft.com/en-us/azure/communication-services/acs-retirement-and-breaking-changes-guide)

## Storage

### [Generally Available: Instant Access for VM restore points](https://azure.microsoft.com/en-us/updates?id=572573)

**Status:** Launched | **Published:** 2026-09-24 | **Products:** Azure Disk Storage, Virtual Machines | **Tags:** Compliance, Management, Feature

Instant Access for application-consistent VM restore points with Premium v2 or Ultra disks is now generally available, enabling immediate disk restoration from snapshots to reduce recovery time objectives.

- Instant Access allows disk restore to start as soon as the snapshot is created, bypassing the wait for full data replication.
- Introduces a new consolidated read-only property 'instantAccessState' on restore points to simplify restore decision-making.
- Supported only for application-consistent restore points on VMs with Premium SSD v2 or Ultra data disks; not supported for crash-consistent restore points.
- Available via REST API, Azure SDK, CLI, and ARM templates; not yet supported in the Azure Portal.

Documentation: [Use virtual machine restore points - Azure Virtual Machines](https://learn.microsoft.com/en-us/azure/virtual-machines/virtual-machines-create-restore-points#instant-access)
