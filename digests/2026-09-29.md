## Databases

### [Generally Available: Vector search and vector indexes in Azure SQL](https://azure.microsoft.com/en-us/updates?id=571800)

**Status:** Launched | **Published:** 2026-09-28 | **Products:** Azure SQL Database | **Tags:** Feature

Azure SQL Database now generally supports vector search and vector indexes using the DiskANN algorithm, enabling efficient AI-driven approximate nearest neighbor searches directly within the database for improved application simplicity and performance.

- Capability: Supports CREATE VECTOR INDEX and VECTOR_SEARCH T-SQL commands for approximate nearest neighbor (ANN) searches using the DiskANN algorithm.
- Availability: Generally available in Azure SQL Database with full DML support, iterative filtering, optimizer-driven execution, and advanced quantization.
- Customer impact: Enables AI-powered applications like semantic search, RAG, recommendations, and image search without needing separate vector databases, simplifying architecture and leveraging Azure SQL's security and governance.
- Migration: Existing vector indexes from earlier versions must be dropped and recreated to access latest features; migration should be planned during maintenance windows to avoid service disruption.

Documentation: [CREATE VECTOR INDEX (Transact-SQL) - SQL Server](https://learn.microsoft.com/en-us/sql/t-sql/statements/create-vector-index-transact-sql?view=sql-server-ver17)

### [Generally Available: Azure SQL Managed Instance updates for late-September 2026](https://azure.microsoft.com/en-us/updates?id=571632)

**Status:** Launched | **Published:** 2026-09-28 | **Products:** Azure SQL Managed Instance | **Tags:** Feature

Azure SQL Managed Instance now generally supports Flexible Memory, allowing independent scaling of memory without changing vCores, plus higher transaction log write throughput in Business Critical tier, enhancing performance and cost efficiency for memory- and write-intensive workloads.

- Flexible Memory is generally available for Business Critical and next-gen General Purpose tiers on premium-series hardware, enabling customizable memory-to-vCore ratios.
- Higher transaction log write throughput limits are supported in Business Critical tier, improving performance for write-intensive workloads.
- Flexible Memory allows online memory scaling with minimal downtime (~60 minutes), managed via Azure Portal, PowerShell, SDK, or API (minimum version 2024-08-01).
- Usage-based pricing charges only for additional memory beyond default allocation, optimizing cost for memory-intensive scenarios like analytics and caching.

Documentation: [Unlocking More Power with Flexible Memory in Azure SQL Managed Instance | Microsoft Community Hub](https://techcommunity.microsoft.com/blog/azuresqlblog/unlocking-more-power-with-flexible-memory-in-azure-sql-managed-instance/4425054)

### [Generally Available: Luxembourg - Azure Extended Zones](https://azure.microsoft.com/en-us/updates?id=572968)

**Status:** Launched | **Published:** 2026-09-28 | **Tags:** Regions & Datacenters

The Luxembourg Azure Extended Zone is now generally available, enabling customers to run low latency and data residency-sensitive workloads closer to end users within specific jurisdictions.

- Azure Extended Zones are small-footprint Azure extensions placed in metro areas or industry centers to support latency-sensitive and data residency workloads.
- The Luxembourg Extended Zone supports a selection of VMs, containers, networking, storage, and other Azure services.
- Customers can deploy and manage virtual machines and Arc-enabled workloads such as AKS clusters, ContainerApps, and Managed SQL Instances within this zone.
- This availability helps enterprises meet data residency requirements while improving application performance by reducing latency.

Documentation: [Azure Extended Zones documentation](https://learn.microsoft.com/en-us/azure/extended-zones/)
