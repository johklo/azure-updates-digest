### [Public Preview: Azure SQL Database Hyperscale Serverless auto-pause and auto-resume](https://azure.microsoft.com/en-us/updates?id=571857)

**Status:** In preview | **Published:** 2026-09-29 | **Products:** Azure SQL Database | **Tags:** Feature

Azure SQL Database Hyperscale Serverless now supports auto-pause and auto-resume in public preview, enabling cost savings by pausing compute during inactivity and resuming on demand.

- Auto-pause stops compute billing during inactivity while storage charges continue, reducing costs for workloads with idle periods.
- Available for new and existing Hyperscale databases using the Serverless compute tier with a minimum auto-pause delay of 60 minutes.
- Certain features like geo-replication, DNS aliases, and sync databases prevent auto-pausing; auto-resume triggers on activity or management operations.
- Applications must implement connection retry logic to handle transient errors during auto-resume, with typical resume latency around one minute.
