### [Public Preview: SQL performance monitoring for SQL Server on Azure Virtual Machines](https://azure.microsoft.com/en-us/updates?id=571894)

**Status:** In preview | **Published:** 2026-09-30 | **Products:** SQL Server on Azure Virtual Machines | **Tags:** Feature

Microsoft has introduced a public preview of managed SQL Server performance monitoring on Azure Virtual Machines, simplifying telemetry collection and analysis without custom scripts.

- The SQL IaaS Agent extension collects and sends SQL Server performance data to a Microsoft-managed telemetry pipeline for processing and storage.
- Resource-level and estate-wide dashboards, integrated with Fabric Database Hub, provide unified monitoring and help identify performance trends and bottlenecks.
- Supports SQL Server 2016 and later Enterprise and Standard editions; Developer, Express, and Evaluation editions collect limited client connection data only.
- Performance data can be securely queried using Kusto Query Language via an RBAC-protected Azure Data Explorer proxy endpoint for deeper analysis.

Documentation: [Enable Performance Monitoring for SQL Server on Azure VMs (Preview) - SQL Server on Azure VMs](https://learn.microsoft.com/en-us/azure/azure-sql/virtual-machines/windows/enable-performance-monitoring-sql-vm?view=azuresql-vm)

### [Retirement: NVv3-series Azure Virtual Machines](https://azure.microsoft.com/en-us/updates?id=573414)

**Status:** Retirement | **Published:** 2026-09-30 | **Products:** Virtual Machines | **Tags:** Retirements

Microsoft Azure retired the NVv3-series virtual machines on September 30, 2026, requiring customers to migrate to supported VM types to maintain service and support.

- Standard_NV12s_v3, Standard_NV12hs_v3, Standard_NV24s_v3, Standard_NV24ms_v3, Standard_NV32ms_v3, and Standard_NV48s_v3 VMs were retired on September 30, 2026.
- Remaining NVv3-series VMs are deallocated, stop working, and no longer incur charges or receive SLA/support.
- Reserved Instance purchases for NVv3-series ended on November 2, 2025.
- Azure UAE North region has an extended retirement date until January 31, 2027, after which migration off NVv3-series VMs is mandatory.

Documentation: [NVv3 series retirement - Azure Virtual Machines](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/lifecycle/retirement/nvv3-series-retirement)

### [Public Preview: Ubuntu 26.04 support in AKS](https://azure.microsoft.com/en-us/updates?id=573214)

**Status:** In preview | **Published:** 2026-09-30 | **Products:** Azure Kubernetes Service (AKS) | **Tags:** Feature

Azure Kubernetes Service (AKS) now supports Ubuntu 26.04 in public preview, offering a smaller host footprint, Linux LTS kernel 7.0, and rollback flexibility to Ubuntu 24.04, helping teams manage OS transitions with improved security and compatibility.

- Ubuntu 26.04 support introduces the Ubuntu2604 OS SKU using Ubuntu Minimal as the baseline image.
- Available in preview for Kubernetes version 1.36 and later; requires registering the Ubuntu2604Preview feature flag.
- Preserves existing AKS workflows for create, update, and node pool management with a controlled migration path and rollback to Ubuntu 24.04 where supported.
- Smaller default host footprint and updated Linux LTS kernel 7.0 improve security and performance for AKS node pools.

Documentation: [Upgrade Operating System (OS) Version in Azure Kubernetes Service (AKS) Clusters - Azure Kubernetes Service](https://learn.microsoft.com/en-us/azure/aks/upgrade-os-version)

### [Retirement: Dv3, Dsv3, Ev3, and Esv3 Azure VMs](https://azure.microsoft.com/en-us/updates?id=572346)

**Status:** Retirement | **Published:** 2026-09-30 | **Products:** Virtual Machines | **Tags:** Retirements

Microsoft is retiring the Dv3, Dsv3, Ev3, and Esv3 Azure VM series by November 15, 2029, requiring customers to migrate to newer VM generations to ensure continued support and improved performance.

- Dv3, Dsv3, Ev3, and Esv3 VM series will retire on November 15, 2029, entering the End-of-Life stage and losing support.
- Customers should migrate workloads to newer VM series like Dsv5 or Esv5 before the retirement date to avoid service interruption.
- Reserved Instances for these VM series stopped being available for purchase or renewal as of July 1, 2026; customers are advised to consider Azure savings plans for continued cost savings.
- Microsoft offers support and migration assistance through active support plans and community resources to help customers transition smoothly.

Documentation: [Manage Azure Reservations - Microsoft Cost Management](https://learn.microsoft.com/en-us/azure/cost-management-billing/reservations/manage-reserved-vm-instance)
