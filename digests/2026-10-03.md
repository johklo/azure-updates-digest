## Databases

### [Public Preview:  Major version upgrades (MVU) for Azure Database for PostgreSQL elastic clusters](https://azure.microsoft.com/en-us/updates?id=571504)

**Status:** In preview | **Published:** 2026-10-02 | **Products:** Azure Database for PostgreSQL | **Tags:** Feature

Azure Database for PostgreSQL elastic clusters now support in-place major version upgrades (MVUs), enabling easier, lower-downtime upgrades without data migration or endpoint changes.

- MVUs allow upgrading elastic clusters to newer PostgreSQL versions without provisioning new clusters or migrating data, reducing downtime and operational complexity.
- The upgrade process includes prechecks, implicit backups, and uses pg_upgrade tool, supporting skipping versions and automatic minor version updates.
- High availability is temporarily disabled during upgrades and re-enabled afterward, requiring sufficient capacity and proper network configurations.
- Certain limitations apply, such as no support for read replicas during upgrades and the need to delete replicas before upgrading; rollback requires point-in-time recovery.

Documentation: [Major Version Upgrades - Azure Database for PostgreSQL](https://learn.microsoft.com/en-us/azure/postgresql/configure-maintain/concepts-major-version-upgrade)
