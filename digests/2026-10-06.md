### [Announcing: Table discovery in OneLake Catalog search](https://azure.microsoft.com/en-us/updates?id=573875)

**Status:** Effective | **Published:** 2026-10-05 | **Products:** Microsoft Fabric | **Tags:** Announcement

Microsoft Fabric Search now includes table discovery from semantic models, lakehouses, and mirrored databases, enhancing data findability while respecting existing permissions.

- Search returns tables as individual results from semantic models, lakehouses, and mirrored databases starting October 15, 2026.
- Users can search tables by name, description, or exact column-name match across multiple Fabric search interfaces.
- Table visibility in search depends on parent item permissions, not data-level permissions; search does not grant data access.
- Admins can control table discovery via the 'Users can find objects in search' setting in the Fabric admin portal, enabled by default.

## Management and governance

### [Public Preview: Azure Backup for PostgreSQL flexible server and elastic cluster (v2)](https://azure.microsoft.com/en-us/updates?id=573425)

**Status:** In preview | **Published:** 2026-10-05 | **Products:** Azure Backup, Azure Database for PostgreSQL | **Tags:** Feature

Azure Backup for PostgreSQL flexible server and elastic cluster (v2) preview introduces physical backups with long-term retention and enhanced scalability, improving backup efficiency and restore capabilities for enterprise-scale PostgreSQL deployments.

- Supports physical backups via managed disk snapshots for flexible servers and elastic clusters up to 32 TB (Premium SSD v1) and 64 TB (Premium SSD v2), overcoming the 1 TB limit of v1 logical backups.
- Provides incremental backups after the initial full backup with daily or weekly schedules, enabling practical multi-terabyte daily protection and configurable retention from 7 days up to 10 years.
- Includes Restore as Server feature allowing direct restore to pre-created PostgreSQL flexible servers or elastic clusters without intermediate storage or manual import.
- Offers enterprise-grade data protection with WORM immutable backups, vault soft delete, multi-user authorization, and customer-managed key encryption to safeguard against ransomware and accidental deletion.

Documentation: [About Azure Backup for PostgreSQL flexible server and elastic cluster (v2) - Azure Backup](https://learn.microsoft.com/en-us/azure/backup/backup-azure-postgresql-flex-server-elastic-cluster-v2-overview)

### [Public Preview: IPv6 Support for Application Gateway WAF](https://azure.microsoft.com/en-us/updates?id=573861)

**Status:** In preview | **Published:** 2026-10-05 | **Products:** Application Gateway, Web Application Firewall | **Tags:** Features, Security

Azure Application Gateway WAF now supports IPv6 traffic inspection and enforcement in Public Preview, enabling consistent security for dual-stack environments as IPv6 adoption grows.

- Application Gateway WAF extends full protection, including managed and custom rules plus diagnostics, to IPv6 traffic in dual-stack deployments.
- IPv6 geo-based custom rules are available during preview via AFEC enrollment, allowing granular traffic governance.
- Dual-stack configuration is required; IPv4-only gateways cannot be upgraded to dual-stack and IPv6-only gateways are unsupported.
- Feature registration is required to enable IPv6 geo-based custom rules, with platform validations preventing unsupported configurations.

Documentation: [IPv6 Geo-Based Custom Rules (Preview) - Azure Web Application Firewall](https://learn.microsoft.com/en-us/azure/web-application-firewall/ag/custom-rules-geo-based-ipv6)
