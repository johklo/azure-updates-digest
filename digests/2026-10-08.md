### [Generally Available: Enabling the Bulk admin role for SQL Server on Linux](https://azure.microsoft.com/en-us/updates?id=573443)

**Status:** Launched | **Published:** 2026-10-07 | **Tags:** Feature

SQL Server on Linux now supports the bulkadmin server role and ADMINISTER BULK OPERATIONS permission to enable bulk data import without requiring sysadmin privileges, enhancing security by enabling least-privilege access.

- Available starting with SQL Server 2025 CU9 and SQL Server 2022 CU27 on Linux, including on-premises, Azure VMs, and containers.
- Allows use of BULK INSERT and OPENROWSET(BULK...) operations without sysadmin role membership, improving security posture.
- Requires Linux file system permissions and explicit directory path approval via mssql-conf for bulk data import operations.
- Supports granting permissions either by adding users to the bulkadmin fixed server role or granting ADMINISTER BULK OPERATIONS permission directly.

Documentation: [Configure Bulk Import Operations for SQL Server on Linux - SQL Server](https://learn.microsoft.com/en-us/sql/linux/security/bulk-operations?view=sql-server-ver17)
