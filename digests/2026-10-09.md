## Compute

### [Generally Available: Managed StandardV2 NAT Gateway for AKS](https://azure.microsoft.com/en-us/updates?id=574430)

**Status:** Launched | **Published:** 2026-10-08 | **Products:** Azure Kubernetes Service (AKS), Azure NAT Gateway | **Tags:** Features

AKS now generally supports provisioning and managing a StandardV2 NAT Gateway for clusters using AKS-managed virtual networks, offering improved performance and zone redundancy.

- StandardV2 NAT Gateway is the new default SKU for managed NAT Gateways in supported regions, replacing Standard SKU for new AKS clusters using managedNATGateway outbound type.
- StandardV2 provides zone redundancy by default, higher bandwidth and throughput, and IPv6 support, enhancing cluster outbound connectivity reliability and performance.
- Existing AKS clusters can migrate from Standard NAT Gateway or load balancer to StandardV2, but downgrades from StandardV2 to Standard are not supported.
- StandardV2 NAT Gateway requires StandardV2 public IP addresses and prefixes, which are incompatible with existing Standard SKU public IP resources, necessitating planning for IP resource management.

Documentation: [Create a Managed or User-Assigned NAT Gateway for your Azure Kubernetes Service (AKS) Cluster - Azure Kubernetes Service](https://learn.microsoft.com/en-us/azure/aks/nat-gateway)

## Networking

### [Generally Available: Exceptions in WAF for Azure Application Gateway and Azure Front Door](https://azure.microsoft.com/en-us/updates?id=574343)

**Status:** Launched | **Published:** 2026-10-08 | **Products:** Application Gateway, Azure Front Door, Web Application Firewall | **Tags:** Features, Security

Azure Web Application Firewall (WAF) on Application Gateway and Front Door now generally supports exceptions that allow specific requests to bypass WAF inspection at granular levels, improving policy tuning and reducing false positives.

- Exceptions can be configured by request URI, remote IP address, or request header name and value to bypass inspection at the rule, rule group, or managed ruleset level.
- Available generally for Azure Application Gateway and Azure Front Door WAF policies via Azure portal and CLI/PowerShell commands.
- Helps customers precisely tune WAF policies by excluding safe, expected requests from inspection while maintaining other protections.
- Limits include up to 60 exceptions per WAF policy and per Application Gateway, with up to 600 IP addresses per exception.

Documentation: [Azure Application Gateway WAF Exceptions List (Preview)](https://learn.microsoft.com/en-us/azure/web-application-firewall/ag/application-gateway-exceptions)
