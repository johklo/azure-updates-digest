## Other

### [Retirement: Azure Key Vault Secrets Provider Extension for Azure Arc enabled Kubernetes clusters](https://azure.microsoft.com/en-us/updates?id=570313)

**Status:** Retirement | **Published:** 2026-10-09 | **Tags:** Retirements

After retirement, the Azure Key Vault Secrets Provider Extension will no longer receive new features, bug fixes, security updates, or technical support.

- Customers currently using the extension should plan to migrate to the Azure Key Vault Secret Store Extension before the retirement date.
- The Azure Key Vault Secrets Provider Extension for Azure Arc-enabled Kubernetes will be retired on October 9, 2027.
- Migration guidance is available to help customers transition their workloads and configurations to the Azure Key Vault Secret Store Extension ahead of retirement.
- The Azure Key Vault Secret Store Extension provides equivalent functionality for accessing and synchronizing secrets from Azure Key Vault for workloads running on Azure Arc-enabled Kubernetes clusters.

Documentation: [Use Azure Key Vault Secrets Provider extension to fetch secrets into Azure Arc-enabled Kubernetes clusters - Azure Arc](https://learn.microsoft.com/en-us/azure/azure-arc/kubernetes/tutorial-akv-secrets-provider)
