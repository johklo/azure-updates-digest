## Networking

### [Generally Available: Standard service endpoint](https://azure.microsoft.com/en-us/updates?id=571025)

**Status:** Launched | **Published:** 2026-10-15 | **Products:** Azure Private Link | **Tags:** Features, Pricing & Offerings, SDK and Tools

Azure Standard Service Endpoint is now generally available, offering scalable, secure IaaS-to-PaaS connectivity with improved manageability and network security integration, addressing limitations of traditional service endpoints.

- Enables associating a single public IP as a network identifier across multiple subnets and VNets within the same tenant and region, simplifying configuration and reducing management overhead.
- Overcomes scalability limits of traditional service endpoints, supporting thousands of connections without resource provider throttling.
- Integrates with network security perimeter to enforce centralized, IP-based access controls for Azure PaaS services like Storage, SQL Database, Cosmos DB, and Key Vault, enhancing security posture.
- Available in Azure public cloud and select national clouds (UsSec and UsNAT), offered as a paid feature billed per VNet per hour.

Documentation: [What is a standard service endpoint? - Azure Private Link](https://learn.microsoft.com/en-us/azure/private-link/service-endpoint-standard-overview)

## Other

### [Generally Availabile: Automatic zone balance for Virtual Machine Scale Sets](https://azure.microsoft.com/en-us/updates?id=576334)

**Status:** Launched | **Published:** 2026-10-15 | **Tags:** Feature

Automatic zone balance for Virtual Machine Scale Sets is now generally available, enabling continuous monitoring and automatic redistribution of VM instances across availability zones to improve application resilience against single-zone outages.

- Automatically detects and rebalances VM instances across two or more availability zones using a create-before-delete approach to minimize downtime.
- Includes safeguards such as respecting instance protection policies, coordinating with Azure Autoscale, and limiting rebalancing to one VM at a time.
- Best suited for stateless workloads and requires application health monitoring, zonal instances, and at least two availability zones.
- Can be enabled via Azure portal, CLI, PowerShell, or REST API, helping customers maintain high availability and zone-level resiliency.

Documentation: [Automatic zone balance for Virtual Machine Scale Sets - Azure Virtual Machine Scale Sets](https://learn.microsoft.com/en-us/azure/virtual-machine-scale-sets/auto-zone-balance-overview)

## Storage

### [Public Preview: Azure Files cross-region data copy and synchronization with Azure Storage Mover](https://azure.microsoft.com/en-us/updates?id=576542)

**Status:** In preview | **Published:** 2026-10-15 | **Products:** Azure Files | **Tags:** Feature

Azure Files-to-Azure Files data copy and synchronization via Azure Storage Mover is now in public preview, enabling secure, incremental cross-region and cross-subscription file share data transfers to support business continuity and data consolidation.

- Supports copying and syncing SMB Azure file shares across storage accounts, regions, and subscriptions within the same Microsoft Entra tenant.
- Enables scheduled incremental transfers with centralized scheduling, monitoring, auditing, and metadata preservation for managed recurring file share copy operations.
- Currently in preview, available via Azure portal only, with support limited to SSD provisioned v2 SMB shares and up to 10 concurrent jobs per subscription per region.
- Facilitates scenarios like disaster recovery, data residency compliance, file share consolidation, and placing data closer to applications or analytics workloads.

Documentation: [Get started with Azure Files-to-Azure Files data copy in Azure Storage Mover (preview)](https://learn.microsoft.com/en-us/azure/storage-mover/azure-files-to-azure-files-copy)
