### [Generally Available: Metrics usage insights for Azure Monitor workspace](https://azure.microsoft.com/en-us/updates?id=577165)

**Status:** Launched | **Published:** 2026-10-19 | **Products:** Azure Monitor | **Tags:** Feature

Metrics usage insights for Azure Monitor workspace is now generally available, enabling customers to monitor and optimize metrics ingestion, usage trends, and costs effectively.

- Provides detailed analysis of metrics usage, ingestion volume, throttling limits, and cost optimization opportunities by sending usage data to a Log Analytics workspace.
- Available for all Azure Monitor workspaces with configuration via diagnostic settings and requires approximately 24 hours for data ingestion before insights are available.
- Includes dashboards for Limits & Usage, Workspace Exploration, Unused Metrics, and Ingestion Volume Change to help identify unused metrics, monitor trends, and investigate cost changes.
- Enables customers to optimize costs by identifying unused metrics to remove and plan capacity based on ingestion volume trends and throttling alerts.

Documentation: [Metrics usage insights in Azure Monitor (Preview) - Azure Monitor](https://learn.microsoft.com/en-us/azure/azure-monitor/metrics/metrics-usage-insights)

## Networking

### [Generally Available: Azure DNS enables DNS-based load balancing through Traffic Manager linked records](https://azure.microsoft.com/en-us/updates?id=573917)

**Status:** Launched | **Published:** 2026-10-19 | **Products:** Azure DNS, Traffic Manager | **Tags:** Features

Azure DNS now supports DNS-based load balancing through direct integration with Azure Traffic Manager linked records, improving performance and DNSSEC compatibility.

- Directly associate Azure DNS record sets with Traffic Manager profiles, eliminating the need for CNAME records to trafficmanager.net.
- Reduces DNS lookup latency and enables DNSSEC compatibility by removing unsigned intermediate hops in DNS resolution.
- Supports up to 50 linked records per Traffic Manager profile, including zone apex (naked domain) support where CNAMEs are not allowed.
- Strictly Typed Profiles enforce endpoint type consistency, reducing misconfigurations and aligning TTL with Traffic Manager health monitoring.

Documentation: [Traffic Manager Linked Records overview - Azure DNS](https://learn.microsoft.com/en-us/azure/dns/dns-traffic-manager-linked-records)
