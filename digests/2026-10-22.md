### [Generally Available: Azure Cosmos DB Safe Key Rotation](https://azure.microsoft.com/en-us/updates?id=576716)

**Status:** Launched | **Published:** 2026-10-21 | **Products:** Azure Cosmos DB | **Tags:** Feature

Azure Cosmos DB Safe Key Rotation is now generally available, providing timestamp metadata for account keys to enhance credential management and reduce service disruptions.

- Introduces timestamp metadata showing when each account key was last used.
- Helps identify active keys before rotating or retiring credentials.
- Reduces risk of service disruptions caused by disabling in-use keys.
- Supports improved credential management, application continuity, and security compliance.

## Identity

### [Announcing: Choose Your Own Telephony (CYOT) for Microsoft Entra](https://azure.microsoft.com/en-us/updates?id=577273)

**Status:** Effective | **Published:** 2026-10-21 | **Products:** Microsoft Entra ID (formerly Azure AD) | **Tags:** Announcement

Microsoft Entra ID will enable organizations to choose their own third-party telephony providers for SMS and voice authentication starting October 30, 2026, supporting regulatory and operational needs while retiring Microsoft-provided telephony by February 1, 2027.

- Starting October 30, 2026, organizations can select supported third-party telephony providers via Microsoft Security Store for SMS and voice authentication.
- Microsoft recommends migrating to phishing-resistant methods like passkeys, reserving telephony for users with specific business, regulatory, or technical requirements.
- Microsoft-provided SMS and voice authentication will retire on February 1, 2027, with mandatory passkey registration for affected users to maintain access.
- Organizations must prepare by identifying users needing telephony, evaluating providers, planning transitions, and validating Azure subscription and purchasing requirements.

Documentation: [Passkeys by default and retirement of Microsoft-provided SMS and voice authentication - Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sms-voice-retirement)
