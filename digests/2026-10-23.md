## Storage

### [Generally Available: ABFS Vectored Read for Azure Data Lake Storage](https://azure.microsoft.com/en-us/updates?id=577618)

**Status:** Launched | **Published:** 2026-10-22 | **Products:** Azure Blob Storage, Azure Data Lake Storage | **Tags:** Feature

ABFS Vectored Read is now generally available, enabling compatible analytics engines to reduce request overhead and improve performance for selective reads in Azure Data Lake Storage without requiring query rewrites or data migration.

- Combines nearby file ranges into fewer asynchronous storage requests to reduce network round trips for selective Parquet queries.
- Compatible Spark workloads can enable the feature via configuration (spark.hadoop.parquet.hadoop.vectored.io.enabled=true) without changing queries.
- Requires Apache Hadoop 3.3.5+ with hadoop-azure module and parquet-hadoop 1.12.3+; not supported in Azure Databricks or Photon runtimes currently.
- Benefits depend on workload characteristics and environment; customers should benchmark selective-read workloads against baselines to measure improvements.

Documentation: [Optimize selective analytics reads in Azure Data Lake Storage with ABFS Vectored Read | Microsoft Community Hub](https://techcommunity.microsoft.com/blog/analyticsonazure/optimize-selective-analytics-reads-in-azure-data-lake-storage-with-abfs-vectored/4564592)
