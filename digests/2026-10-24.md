## Management and governance

### [Generally Available: Item Level Recovery for Azure VMs with Premium SSDv2 and Ultra Disks in Azure Backup](https://azure.microsoft.com/en-us/updates?id=577963)

**Status:** Launched | **Published:** 2026-10-23 | **Products:** Azure Backup | **Tags:** Feature

Azure Backup now supports Item-Level Recovery for Azure VMs using Premium SSD v2 and Ultra disks, enabling selective file and folder recovery without full VM restore, enhancing recovery flexibility and efficiency.

- Supports Item-Level Recovery (ILR) for Azure VMs with Premium SSD v2 and Ultra disks with both 512 byte and 4KB logical sector sizes.
- Users can generate a recovery executable or script via Azure portal, CLI, or PowerShell to selectively browse and recover files/folders from recovery points.
- Eliminates the need for full disk or VM restore when recovering individual files, improving recovery speed and reducing downtime.
- Brings parity in ILR capabilities across different disk types, expanding recovery options for enterprise customers using premium storage.

Documentation: [What's new in the Azure Backup service - Azure Backup](https://learn.microsoft.com/en-us/azure/backup/whats-new#item-level-recovery-support-for-premium-ssd-v2-and-ultra-disks)
