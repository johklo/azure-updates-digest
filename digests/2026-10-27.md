## Management and governance

### [Generally Available: Network Watcher VNet flow logs filtering](https://azure.microsoft.com/en-us/updates?id=577782)

**Status:** Launched | **Published:** 2026-10-26 | **Products:** Network Watcher | **Tags:** Features

Azure Network Watcher VNet flow logs filtering is now generally available, allowing customers to selectively log network traffic flows to improve monitoring efficiency and reduce storage costs.

- Enables filtering of VNet flow logs based on IP addresses, ports, protocols, encryption state, flow state, and traffic direction.
- Available through both Azure portal and PowerShell, simplifying configuration and management.
- Helps reduce log volume and storage costs by capturing only relevant network traffic flows.
- Supports logical operator precedence in filters and allows customization of flow record types during creation or update.

Documentation: [Filter Virtual Network Flow Logs - Azure Network Watcher](https://learn.microsoft.com/en-us/azure/network-watcher/vnet-flow-logs-filtering)
