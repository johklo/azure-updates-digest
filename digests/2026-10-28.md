**Status:** Launched | **Published:** 2026-10-27 | **Products:** Microsoft Foundry | **Tags:** Feature

## Networking

### [Generally Available: Azure Front Door profile and route level WAF policies](https://azure.microsoft.com/en-us/updates?id=578153)

**Status:** Launched | **Published:** 2026-10-27 | **Products:** Azure Front Door, Web Application Firewall | **Tags:** Features, Security

Azure Front Door Premium now supports general availability of WAF policies at profile and route levels, enabling broader baseline protection and more granular controls to reduce policy duplication and enhance security management.

- WAF policies can be applied at profile, domain, or route scopes, with route-level policies taking precedence over domain and profile levels.
- Profile-level policies provide broad baseline protection across all domains in a Front Door profile, while route-level policies allow targeted controls for sensitive paths.
- This capability reduces policy duplication for teams managing multiple applications behind a single Azure Front Door profile.
- Existing domain-level WAF policy associations continue to function without changes, ensuring backward compatibility.

Documentation: [What Is Azure Web Application Firewall on Azure Front Door?](https://learn.microsoft.com/en-us/azure/web-application-firewall/afds/afds-overview#policy-attachment-scopes)

## Storage

### [Generally Available: Higher limit of Azure Blob Storage accounts per region per subscription](https://azure.microsoft.com/en-us/updates?id=578358)

**Status:** Launched | **Published:** 2026-10-27 | **Products:** Azure Blob Storage | **Tags:** Management

Azure Blob Storage accounts per region per subscription quota has increased from 250 to 1,000, enabling customers to manage more storage accounts within a single subscription for better resource consolidation.

- Quota for standard endpoint storage accounts increased to 1,000 per region per subscription, up from 250.
- Quota increase requests can be made via Azure Portal, CLI, or PowerShell without support tickets.
- Storage Resource Provider API operations scale automatically to support higher approved quotas.
- Change applies to account management operations, not data plane operations within storage accounts.

Documentation: [Increase Azure Storage account quotas - Azure Quotas](https://learn.microsoft.com/en-us/azure/quotas/storage-account-quota-requests)
