## Networking

### [Generally Available: HTTP DDoS ruleset for Azure Front Door Premium WAF](https://azure.microsoft.com/en-us/updates?id=578681)

**Status:** Launched | **Published:** 2026-10-29 | **Products:** Azure Front Door, Web Application Firewall | **Tags:** Features, Security

Azure Front Door Premium WAF's HTTP DDoS ruleset is now generally available, providing adaptive, automated layer 7 DDoS protection that baselines traffic and mitigates attacks with minimal configuration, enhancing application uptime and security.

- Automated traffic baselines at profile and per-client levels with three sensitivity settings enable adaptive detection and mitigation of HTTP-layer DDoS attacks.
- Two GA rules target anomalously high request rates and suspected bots using Microsoft Threat Intelligence, with additional geo rules in preview to handle distributed attacks by country/region.
- WAF exceptions allow trusted traffic like health probes and load tests to bypass the ruleset, minimizing false positives and operational impact.
- All rules default to Log action for safe evaluation before enforcement, with monitoring metrics available to track rule matches and ruleset activity.

Documentation: [HTTP DDoS Ruleset - Front Door WAF](https://learn.microsoft.com/en-us/azure/web-application-firewall/afds/http-ddos-ruleset)

### [Generally Available: Large OS Disk Encryption for Azure Confidential VM migrations](https://azure.microsoft.com/en-us/updates?id=578850)

**Status:** Launched | **Published:** 2026-10-29 | **Tags:** Feature

Large OS Disk Encryption (LOSDE) is now generally available for Azure Confidential VM migrations, enabling secure migration of larger OS disks into confidential computing environments without shrinking or re-encrypting images.

- Supports migration of OS disks larger than 127 GB for Windows, Ubuntu, Red Hat Enterprise Linux, and Rocky Linux workloads.
- Encrypts OS disks with confidential disk encryption bound to the VM's virtual TPM, ensuring disk content is accessible only to the VM after attestation.
- Allows use of customer-managed keys backed by Azure Key Vault Premium or Managed HSM, maintaining customer control over encryption keys.
- Integrates with Azure Migrate to automate secure migration workflows, simplifying cloud modernization and expanding adoption of Azure Confidential VMs.

Documentation: [Large OS Disk Encryption is now generally available for Azure Confidential VM migrations | Microsoft Community Hub](https://techcommunity.microsoft.com/blog/microsoft-security-blog/large-os-disk-encryption-is-now-generally-available-for-azure-confidential-vm-mi/4564613)
