## Databases

### [Public Preview: Support database-level managed identity (including FIC) in Create Database Scoped Credential T-SQL](https://azure.microsoft.com/en-us/updates?id=577491)

**Status:** In preview | **Published:** 2026-10-30 | **Products:** Azure SQL Database | **Tags:** Feature

Azure SQL Database now supports database-level user-assigned managed identities for authenticating queries to Azure Blob Storage and ADLS Gen2, enhancing security by isolating access per database and eliminating the need for shared secrets.

- Enables assigning a unique user-assigned managed identity to each database to authenticate external data queries without SAS tokens or shared server identities.
- Supports both same-tenant and cross-tenant scenarios, including integration with customer-managed keys and federated client IDs for encryption key access.
- Available in public preview, allowing fine-grained access control by granting storage permissions per database, reducing secret management overhead and improving data isolation.
- Uses familiar T-SQL commands like CREATE DATABASE SCOPED CREDENTIAL with IDENTITY = 'DATABASE MANAGED IDENTITY' to configure authentication for external tables and OPENROWSET queries.

Documentation: [Use Database-Level Managed Identity with Azure SQL Database - Azure SQL Database](https://learn.microsoft.com/en-us/azure/azure-sql/database/database-level-managed-identity?view=azuresql)
