## Databases

### [Generally Available: Change from virtual network integration to a private endpoint capable network configuration in Azure Database for PostgreSQL flexible server](https://azure.microsoft.com/en-us/updates?id=574541)

**Status:** Launched | **Published:** 2026-11-02 | **Products:** Azure Database for PostgreSQL | **Tags:** Feature

Azure Database for PostgreSQL Flexible Server now allows migration from virtual network integration to a private endpoint-capable network configuration, enhancing secure access via private IP addresses.

- Enables changing existing VNet-integrated servers to private endpoint-capable configuration for secure Azure Private Link access.
- Migration takes about 20 minutes with up to 10 minutes of server inaccessibility and requires reconfiguration of connectivity options post-migration.
- Existing backups, including geo-redundant ones, remain intact; however, logical replication subscribers may need network adjustments to maintain connectivity.
- The change is irreversible and requires updating infrastructure-as-code scripts like Terraform to reflect the new network setup.

Documentation: [Change from Virtual Network Integration to a Private Endpoint-Capable Network Configuration in Azure Database for PostgreSQL Flexible Server - Azure Database for PostgreSQL](https://learn.microsoft.com/en-us/azure/postgresql/network/how-to-migrate-vnet-private-endpoint-capable-server?tabs=portal-migrate)

### [Retirement: OT security in Microsoft Defender for IoT](https://azure.microsoft.com/en-us/updates?id=576255)

**Status:** Retirement | **Published:** 2026-11-02 | **Tags:** Retirements

Microsoft Defender for IoT's OT security component will be deprecated by October 2029 to encourage customers to transition to third-party OT security solutions integrated via OT data connectors, ensuring continued OT asset and vulnerability visibility within Microsoft Security Exposure Management.

- Defender for IoT OT Security will be fully deprecated in October 2029 after a three-year transition period; existing deployments remain supported with security updates but no new OT features.
- Enterprise IoT capabilities in Microsoft Defender for Endpoint and device discovery/vulnerability assessments remain unaffected.
- Microsoft supports integration with third-party OT security providers (Armis, Dragos, Forescout) via OT data connectors that import OT asset and vulnerability data into the Defender portal.
- Customers must plan and complete migration to alternative OT security solutions before October 2029 to maintain OT security visibility and management within Microsoft Security Exposure Management.

Documentation: [OT data connectors in Microsoft Security Exposure Management - Microsoft Security Exposure Management](https://learn.microsoft.com/en-us/security-exposure-management/ot-data-connectors)

**Status:** Launched | **Published:** 2026-11-02 | **Products:** Azure Blob Storage, Azure Data Lake Storage, Azure Storage Actions | **Tags:** Services, Feature

Azure Storage Actions is now generally available with enhancements including automatic task update propagation, the ability to stop in-progress task runs, and new case-sensitive string operators, improving task management and precision in data operations.

- Automatic propagation of task definition updates ensures changes apply to existing assignments without manual updates, maintaining consistent data management.
- Users can now asynchronously stop in-progress task assignment runs individually or across all assignments, providing greater control over task execution.
