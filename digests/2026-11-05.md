### [Generally Available: Route maps for Azure Route Server](https://azure.microsoft.com/en-us/updates?id=578966)

**Status:** Effective | **Published:** 2026-11-04 | **Products:** Azure Route Server | **Tags:** Features

Azure Route Server route maps are now generally available, enabling fine-grained control over inbound and outbound routing for hybrid connections, improving route management and network traffic optimization.

- Route maps allow route summarization, filtering, BGP attribute modification (AS path, community), and tagging for precise route control.
- Applicable to BGP peerings with NVAs, ExpressRoute gateways, VPN gateways, and virtual network connections within the same virtual network or peered spokes.
- Supports inbound and outbound route maps to control routes received and advertised by Azure Route Server, enhancing hybrid network routing flexibility.
- Helps customers optimize routing policies, reduce route complexity, and manage route advertisements effectively across hybrid Azure environments.

Documentation: [About route maps for Azure Route Server](https://learn.microsoft.com/en-us/azure/route-server/route-maps-about)

### [Public Preview: Azure Firewall IPv6 now supports application rules](https://azure.microsoft.com/en-us/updates?id=579507)

**Status:** In preview | **Published:** 2026-11-04 | **Products:** Azure Firewall | **Tags:** Features, Security

Azure Firewall now supports application rules for IPv6 traffic in public preview, enabling layer 7 filtering for IPv6 HTTP and HTTPS traffic to maintain consistent security policies across IPv4 and IPv6 environments.

- Application rules for Azure Firewall fully support IPv6 traffic, allowing creation of allow or deny rules for IPv6 HTTP/S traffic.
- This feature is in public preview and extends application-level controls to IPv6 and dual-stack deployments.
- Customers can upgrade existing Azure Firewalls to dual stack mode by adding IPv6 address spaces, subnets, and public IPs, but cannot revert back to IPv4-only mode during preview.
- Some features like threat intelligence, IDPS, explicit proxy, and IP groups are not yet supported for IPv6 in dual stack mode.

Documentation: [Deploy Azure Firewall in dual stack mode (preview)](https://learn.microsoft.com/en-us/azure/firewall/deploy-dual-stack-firewall?tabs=portal)

### [Public Preview: Multi-disk crash-consistent VM restore points for Premium SSD v2 and Ultra Disks on VMs with SCSI disk controller](https://azure.microsoft.com/en-us/updates?id=579162)

**Status:** In preview | **Published:** 2026-11-04 | **Products:** Azure Disk Storage, Virtual Machines | **Tags:** Compliance, Management, Feature

Azure now offers public preview of multi-disk crash-consistent restore points for VMs with Premium SSD v2 and Ultra disks on SCSI controllers, enabling faster and agent-less VM recovery.

- Supports multi-disk crash-consistent restore points on VMs with Premium SSD v2 and Ultra data disks using SCSI disk controllers.
- Instant Access feature allows immediate disk restoration after restore point creation, reducing recovery time objectives.
- Requires setting consistencyMode to CrashConsistent when creating restore points; legacy VM tagging needed to avoid Azure Boost hardware placement.
- Supports Windows Server 2016/2019/2022 and endorsed Linux distributions; excludes ephemeral OS disks, shared disks, and 32-bit OS.

Documentation: [Support matrix for VM restore points - Azure Virtual Machines](https://learn.microsoft.com/en-us/azure/virtual-machines/concepts-restore-points#multi-disk-crash-consistency-for-premium-ssd-v2-and-ultra-disks-public-preview)
