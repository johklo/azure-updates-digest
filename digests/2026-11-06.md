## Networking

### [Generally Available: Azure Front Door TLS key exchange policy with post-quantum support](https://azure.microsoft.com/en-us/updates?id=577668)

**Status:** Launched | **Published:** 2026-11-05 | **Products:** Azure Front Door | **Tags:** Features, Security

Azure Front Door now offers configurable TLS key exchange policies with hybrid post-quantum support to enhance security against evolving cryptographic threats while maintaining client compatibility.

- Supports predefined Standard and Enhanced policies or Custom policies to select classical and hybrid post-quantum key exchange groups, including X25519.
- Hybrid post-quantum key exchange requires TLS 1.3 and secures client-to-edge connections, not edge-to-origin connections.
- Allows disabling TLS_AES_128_GCM_SHA256 cipher suite when TLS 1.3 is the minimum version for finer control over TLS encryption.
- Customers must test client compatibility and monitor handshake success to ensure seamless deployment and maintain application connectivity.

Documentation: [TLS Key Exchange Policy - Azure Front Door](https://learn.microsoft.com/en-us/azure/frontdoor/tls-key-exchange-policy)

### [Generally Available: WAF Insights for Azure Application Gateway](https://azure.microsoft.com/en-us/updates?id=579280)

**Status:** Launched | **Published:** 2026-11-05 | **Products:** Application Gateway, Web Application Firewall | **Tags:** Features, Security

Azure Application Gateway WAF Insights is now generally available, providing integrated dashboards for easier monitoring and investigation of WAF activity without query writing, enhancing security operations and incident response.

- WAF Insights combines logs and metrics in interactive dashboards within the WAF policy for detailed monitoring and investigation.
- Supports Azure Diagnostics logs with renamed Investigate tab (formerly Triage) and counts requests by final WAF outcome for accuracy.
- Monitor tab offers high-level trend tracking; Investigate tab enables drill-down from rules or URLs to specific requests and matched rules.
- Helps identify blocked requests, analyze attack patterns, detect false positives, and supports operational awareness and incident workflows.

Documentation: [Azure Application Gateway WAF Insights (Preview)](https://learn.microsoft.com/en-us/azure/web-application-firewall/ag/insights)
