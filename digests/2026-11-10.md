### [Retirement: Support for .NET 8 and .NET 9 on Static Web Apps is ending November 10, 2026](https://azure.microsoft.com/en-us/updates?id=575106)

**Status:** Retirement | **Published:** 2026-11-09 | **Products:** Static Web Apps | **Tags:** Retirements

Support for .NET 8 and .NET 9 on Azure Static Web Apps managed Functions APIs will end on November 10, 2026, requiring customers to upgrade to .NET 10 to maintain security, support, and performance.

- Support and security updates for .NET 8 and .NET 9 on Azure Functions end November 10, 2026; apps will continue running but without patches.
- Customers must migrate managed Functions APIs to .NET 10, updating project files, packages, and configuration to the isolated worker model if applicable.
- The default runtime for Azure Static Web Apps managed Functions APIs will switch to .NET 10 after the retirement date; explicit apiRuntime settings ensure correct runtime usage.
- Linked (bring-your-own) Function Apps have a separate upgrade and deployment lifecycle and must be updated independently.

Documentation: [Azure Functions language stack support policy](https://learn.microsoft.com/en-us/azure/azure-functions/language-support-policy)

### [Public Preview: Modernize Arc-enabled Windows Servers with Azure File Sync](https://azure.microsoft.com/en-us/updates?id=579854)

**Status:** In preview | **Published:** 2026-11-09 | **Tags:** Feature

Azure File Sync now offers a guided Azure portal experience in public preview to simplify onboarding of Arc-enabled Windows Servers, streamlining deployment and management of hybrid file services.

- Provides a unified, guided workflow in the Azure portal for agent installation, server registration, and sync configuration with Azure file shares.
- Supports hybrid file data centralization by syncing Windows Server files to Azure Files while maintaining local file server access.
- Enables cloud tiering to optimize local storage by keeping frequently accessed files locally and tiering others to Azure.
- Simplifies Azure File Sync deployment and management for organizations using Azure Arc to manage Windows Servers.

Documentation: [Deploy Azure File Sync](https://learn.microsoft.com/en-us/azure/storage/file-sync/file-sync-deployment-guide?tabs=azure-portal%2Cproactive-portal#install-on-azure-arc-enabled-servers)
