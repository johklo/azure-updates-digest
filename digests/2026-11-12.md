## Networking

### [Public Preview: Rate limit grouping for Azure Front Door Premium WAF](https://azure.microsoft.com/en-us/updates?id=580155)

**Status:** In preview | **Published:** 2026-11-11 | **Products:** Azure Front Door, Web Application Firewall | **Tags:** Features

Azure Front Door Premium WAF now supports rate limit grouping by JA4 fingerprint, AS number, country/region, or none to better mitigate distributed attacks by aggregating request counts across shared client attributes.

- Introduces public preview of rate limit grouping to count requests by shared client attributes beyond IP address.
- Grouping options include JA4 fingerprint, AS number, country/region, or None, enabling more effective blocking of distributed attacks.
- Available only on Azure Front Door Premium and configurable via Azure portal, ARM templates, Bicep, REST API, or PowerShell.
- Helps customers cap traffic from attack sources that rotate IPs or originate from specific networks or regions, improving protection accuracy.

Documentation: [WAF Rate Limiting for Azure Front Door](https://learn.microsoft.com/en-us/azure/web-application-firewall/afds/waf-front-door-rate-limit)
