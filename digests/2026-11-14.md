### [Retirement: Azure Data Share will be retired on November 12, 2029](https://azure.microsoft.com/en-us/updates?id=578818)

**Status:** Retirement | **Published:** 2026-11-13 | **Products:** Azure Data Share | **Tags:** Retirements

Azure Data Share will be retired on November 12, 2029, requiring customers to transition data sharing workloads to Microsoft Fabric or other data-source-specific sharing options to ensure continued functionality and support.

- Azure Data Share retirement date set for November 12, 2029, impacting data providers, recipients, and applications using snapshot-based or in-place sharing.
- Transition options include Microsoft Fabric external data sharing, cross-tenant delegated shortcuts, IQ Share, Azure Data Factory pipelines, and Azure SQL Database data virtualization.
- No automatic migration path exists; customers must inventory shares, subscriptions, schedules, and dependencies, and validate access, networking, and data completeness before cutover.
- Customers should continue using Azure Data Share until retirement and coordinate with Microsoft account teams for transition planning and support.

Documentation: [Azure Data Share retirement](https://learn.microsoft.com/en-us/azure/data-share/retirement)
