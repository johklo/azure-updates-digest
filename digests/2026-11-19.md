### [Announcing: The new Azure Databricks on Azure Government is now in Beta](https://azure.microsoft.com/en-us/updates?id=581645)

**Status:** Effective | **Published:** 2026-11-18 | **Products:** Azure Databricks | **Tags:** Microsoft Ignite, Announcement

Azure Databricks is now available in Beta on Azure Government, providing U.S. public sector agencies with a secure, scalable data and AI platform tailored for non-production workloads.

- Includes Unity Catalog for unified governance and Databricks SQL with serverless compute for scalable analytics.
- Features system tables for usage, audit, and cost visibility to enhance operational insights.
- Compliance Security Profile enabled by default, requires Azure Private Link, and data residency is restricted to US Gov Virginia and Arizona regions.
- Beta access is subscription-based and limited to non-production workloads, excluding Controlled Unclassified Information (CUI) or regulated data.

## Management and governance

### [Generally Available: Cross-subscription backup for Azure Virtual Machines in Azure Backup](https://azure.microsoft.com/en-us/updates?id=581048)

**Status:** Launched | **Published:** 2026-11-18 | **Products:** Azure Backup | **Tags:** Management, Microsoft Ignite, Feature

Azure Backup now supports cross-subscription backup for Azure Virtual Machines, allowing centralized backup management across subscriptions within the same tenant, which simplifies administration and enhances governance.

- Enables backing up Azure VMs using a Recovery Services vault located in a different subscription within the same tenant.
- Supports centralized backup management, reducing the need for separate backup vaults per subscription.
- Improves governance and simplifies backup administration for enterprises with multiple subscriptions.
- Particularly beneficial for large Azure environments with dedicated subscriptions for backup and security operations.

Documentation: [Back Up Azure VMs in a Recovery Services Vault - Azure Backup](https://learn.microsoft.com/en-us/azure/backup/backup-azure-arm-vms-prepare#apply-a-backup-policy)

## Networking

### [Public Preview: AI bot ruleset for Azure Front Door Premium WAF](https://azure.microsoft.com/en-us/updates?id=581604)

**Status:** In preview | **Published:** 2026-11-18 | **Products:** Azure Front Door, Web Application Firewall | **Tags:** Features, Microsoft Ignite, Security

Azure Front Door Premium WAF introduces a public preview AI bot ruleset that categorizes and manages AI bots to help enterprises control AI crawler traffic at the edge, enhancing security and content access management.

- The AI bot ruleset identifies AI bots in four categories—AI training, AI search, AI interactive agents, and miscellaneous AI agents—and allows configurable actions like Allow, Block, Log, JS challenge, or CAPTCHA per category.
- Microsoft manages and updates AI bot signatures automatically without requiring ruleset version changes, ensuring up-to-date detection.
- By default, all rules log AI bot traffic before blocking, enabling customers to review traffic patterns before enforcing restrictions.
- Available in Azure Front Door Premium with a Premium tier WAF policy, this capability helps enterprises selectively allow or block AI crawlers, protecting content and controlling AI-driven access.

Documentation: [AI Bot Ruleset (Preview) - Front Door WAF](https://learn.microsoft.com/en-us/azure/web-application-firewall/afds/ai-bot-ruleset)
