### [Generally Available: Soft delete in Azure Compute Gallery](https://azure.microsoft.com/en-us/updates?id=581907)

**Status:** Launched | **Published:** 2026-11-19 | **Tags:** Features, Microsoft Ignite

Azure Compute Gallery now generally supports Soft Delete, allowing recovery of accidentally deleted image versions with configurable retention and grace periods, enhancing data protection and operational continuity.

- Soft Delete enables recovery of deleted image versions with a retention period of 7 to 365 days during which images remain deployable (API version 2026-03-03).
- After retention, a grace period of 7 to 90 days allows recovery but blocks deployments; permanent deletion occurs after the grace period.
- Supported in 24 Azure regions and works with Private, Direct Shared, and Community galleries; enabling Soft Delete requires specific permissions and regional alignment of gallery resources.
- Soft Delete is free but retained images incur charges until permanent deletion; it can be enabled on new or existing galleries via Azure portal, CLI, PowerShell, or REST API.

Documentation: [Soft Delete in Azure Compute Gallery - Azure Virtual Machines](https://learn.microsoft.com/en-us/azure/virtual-machines/soft-delete-gallery)

### [Public Preview: Zone resilience for Azure VMs](https://azure.microsoft.com/en-us/updates?id=581254)

**Status:** In preview | **Published:** 2026-11-19 | **Tags:** Features, Microsoft Inspire

Azure VMs now support zone resilience in public preview, enabling recovery of zonal VMs in a different availability zone within the same region while retaining the original VM resource and configuration, improving recovery flexibility and minimizing data loss.

- Allows changing the VM's availability zone without creating a new VM resource.
- Recovers VMs using existing OS and data disks with near-zero recovery point objective for committed data.
- Customer-initiated recovery option requiring downtime and target zone capacity; not an automatic failover.
- Currently supports standalone zonal VMs with Premium SSD ZRS or Standard SSD ZRS disks; excludes VM Scale Sets, capacity reservations, Azure Site Recovery, and write-accelerated disks.
