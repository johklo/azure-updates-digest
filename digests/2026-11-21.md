### [Retirement: Support for Azure Functions OpenAI Extension ends on April 20, 2027](https://azure.microsoft.com/en-us/updates?id=579952)

**Status:** Retirement | **Published:** 2026-11-20 | **Products:** Azure Functions | **Tags:** Retirements, Microsoft Ignite

Support for the Azure Functions OpenAI extension will end on April 20, 2027, requiring customers to migrate to direct SDKs to maintain support and security.

- Azure Functions OpenAI extension support ends April 20, 2027; post this date, no security updates, patches, or technical support will be provided.
- Customers must migrate to OpenAI, Microsoft Foundry, or Azure AI Search SDKs depending on their scenario before the retirement date.
- Until migration, .NET apps will continue running; non-.NET apps must use preview extension bundle versions earlier than 4.60.0 to remain functional but unsupported.
- Running apps on unsupported extension versions after retirement may cause issues and degraded performance, so migration is recommended to minimize security risks and leverage latest features.

Documentation: [Azure OpenAI extension for Azure Functions](https://learn.microsoft.com/en-us/azure/azure-functions/functions-bindings-openai)
