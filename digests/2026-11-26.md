## Compute

### [Retirement: Support for Java 8, 11 and 17 in Azure Functions ends on September 1, 2027](https://azure.microsoft.com/en-us/updates?id=568586)

**Status:** Retirement | **Published:** 2026-11-25 | **Products:** Azure Functions | **Tags:** Retirements

Azure Functions will retire support for Java 8, 11, and 17 on September 1, 2027, requiring customers to upgrade to Java 25 to maintain security and support.

- Support for Java 8, 11, and 17 in Azure Functions ends on September 1, 2027; apps will run but without security updates or customer support.
- Customers must upgrade their Function apps to Java 25 before the deadline to avoid security vulnerabilities and access new features.
- Updating involves migrating to the isolated worker model if using in-process, updating dependencies, testing locally, and ensuring runtime version 4.x.
- Microsoft provides detailed guidance on updating language versions, managing dependencies, and using deployment slots to minimize downtime.

Documentation: [Update Language Versions in Azure Functions](https://learn.microsoft.com/en-us/azure/azure-functions/update-language-versions?tabs=azure-portal%2Cwindows&pivots=programming-language-java)

## Networking

### [Public Preview: ECMP Nexthop](https://azure.microsoft.com/en-us/updates?id=582326)

**Status:** In preview | **Published:** 2026-11-25 | **Products:** Virtual Network | **Tags:** Management, Services, Feature

Azure Virtual Network now supports Equal-Cost Multi-Path (ECMP) routing in public preview, allowing traffic distribution across multiple network appliances via a single user-defined route to enhance throughput and simplify routing.

- Enables configuration of 2 to 16 next-hop IP addresses per user-defined route for load distribution.
- Supports bandwidth-intensive workloads like AI, large-scale data platforms, and hub-and-spoke architectures.
- Available in public preview requiring Microsoft.Network/AllowEcmpInRoute feature registration.
- Helps scale aggregate network throughput beyond individual appliance limits without added routing complexity.

Documentation: [Azure virtual network traffic routing](https://learn.microsoft.com/en-us/azure/virtual-network/virtual-networks-udr-overview#equal-cost-multipath-routing-for-user-defined-routes-public-preview)
